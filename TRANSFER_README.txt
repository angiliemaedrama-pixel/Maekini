MAEKINI STORE - TRANSFER PACKAGE

CONTENTS
- index.html, style.css, script.js: storefront files
- server.js: local Node.js server and SQLite database setup
- admin.html: admin page
- start-maekini.bat: Windows launcher
- assets/products/1 through 57: product photos

RUN ON A NEW WINDOWS PC
1. Extract this ZIP completely. Do not run it from inside the ZIP preview.
2. Install Node.js 22 or newer from https://nodejs.org/ .
3. Open the extracted Maekini_Store folder.
4. Double-click start-maekini.bat. It opens the storefront. If Windows blocks it, open a terminal in this folder and run: node server.js
5. Keep the terminal window open. Visit http://localhost:3000 in Chrome or Edge.
6. Storefront: http://localhost:3000/

DATABASE
The server creates maekini.db automatically when it first runs. If you have an existing maekini.db containing customer records on your old PC, copy that file from the old project folder into this Maekini_Store folder before starting the server on the new PC. Back it up first.
